## Overview

To setup and run the application, it is important to install all the necessary dependencies, start the socket server and run the JoyRoom App.
Node v20 is preferred.

### Install All Deps

bun install

# or

yarn install

# or

npm install

### Start Socket Server

bun socket

# or

npm socket

### Run JoyRoom App

bun dev

# or

yarn dev

# or

npm dev
